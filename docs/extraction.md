# 独立项目提取说明

本仓库从知语的通用记忆实现建立独立历史，不复制知语整个 Git 历史，避免带入旧运行数据、配置与构建产物。来源提交和复制前的摘要见 `extraction.json`。核心源码保持提取版本，入口、相对路径、测试管理、依赖声明和文档按独立项目调整。

服务入口从示例移动到 `apps/service/main.ts`，本地管理入口为 `apps/service/admin.ts`。默认项目装配仍使用研发项目示例，保留其名字来标明适用范围。其他项目替换 Adapter 与策略；不需要知语数据库迁移。

独立项目验证：干净依赖安装、TypeScript、27 项核心单元测试、应用依赖隔离、真实 PostgreSQL 的进程内 14 组与跨进程 14 组验收。后续验证状态以当前提交的 GitHub Actions 和本地 `.runtime/integration.json` 为准；本说明不代替某次运行结果。

另提供快速开始脚本：显式初始化、最小权限演示成员、私有凭证文件、中文观测保存/精确读取/幂等重试与合成接收器。演示成员无 review 权限，不自动批准任何长期知识。

知语保持原有代码、本地 Adapter、当前数据库与桌面入口，本次拆出不会自动将日常入口改成远程依赖。独立仓库可后续单独部署、迭代和接入；跨仓库版本升级应先跑相同闭环和隔离验收，再显式切换。
